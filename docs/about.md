# 关于这个站点

这里是我的个人笔记站，用来沉淀开发、运维、工具链和日常折腾中的有效记录。

## 站点定位

- 以可回查、可复用为主，不追求花哨排版。
- 首页和归档页强调“深空档案库”氛围，正文页保持阅读优先。
- 内容会持续补充 frontmatter、标签和摘要，方便后续扩展归档、筛选和导航能力。

## 内容范围

- 前端与工程化
- 运维与环境配置
- 工具链与效率实践
- 个人项目过程记录

## 使用说明

- 首页适合快速浏览最近更新与主题分布。
- 归档页适合按标签和时间集中查看所有笔记。
- 正文页适合长时间阅读与复制命令、代码片段。
